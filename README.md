# Projekt: Web o AI technologiích

## 1. Téma
Téma tohoto webu je **AI technologie** – vysvětlení pojmů, přehled technologií a praktické využití.

## 2. Vytvoření repozitáře
Byl vytvořen nový repozitář na GitHubu:
- název repozitáře: ai-web-technologie
- projekt je otevřen ve Visual Studio / VS Code

## 3. Tvorba webu pomocí AI
Web má tři české stránky:
- index.html
- technologie.html
- vyuziti.html

## 4. Použité AI nástroje
- **ChatGPT** – generování textů, HTML, CSS
- **Microsoft Copilot** – úpravy textu, návrhy
- **DeepSite.io** – inspirace pro design
- **GitHub Copilot** – drobné opravy a návrhy kódu

## 5. Postup tvorby (prompty)
- „Napiš mi web o AI technologiích se 3 českými stránkami.“
- „Navrhni HTML a CSS pro jednoduchý školní web.“
- „Vytvoř README podle školního zadání.“
- „Popiš technologie, které AI použila.“

## 6. Technologie použité AI
- Generativní modely (GPT) na generování kódu a textu  
- NLP pro zpracování přirozeného jazyka  
- Autocomplete technologie (Copilot)  
- Machine Learning modely pro návrhy designu

## 7. Odevzdání
Repozitář obsahuje:
- HTML soubory
- CSS
- README.md

Adresu webu hostovaného přes GitHub Pages a odkaz na repo vložím do Teams.
